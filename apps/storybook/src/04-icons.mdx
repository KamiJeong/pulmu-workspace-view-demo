# 04 Icons

**Library:** [Lucide React 1.34.0](https://www.npmjs.com/package/lucide-react/v/1.34.0)  
**License:** [ISC](https://github.com/lucide-icons/lucide/blob/main/LICENSE)

<p lang="ko">
  Pulmu는 Lucide outline glyph를 adapter를 통해 사용합니다. 기본 크기는 20px, compact 크기는 16px이며 stroke는 2px입니다.
</p>

## Rules

- 일반 UI, lifecycle status, Pulmu stage, brand icon은 각 registry에서 분리합니다.
- 7개 stage의 canonical emoji와 이름은 유지하며 Lucide glyph는 이를 보조합니다.
- Pattern은 여덟 번째 stage가 아니라 Shape 내부의 conditional design pass입니다.
- 아이콘만 있는 button의 accessible name은 parent control에 둡니다.
- 장식 SVG는 assistive technology에서 숨기고 focus 대상에서 제외합니다.
- Status는 visible text와 함께 표시하며 icon이나 색만으로 전달하지 않습니다.
- Loading glyph는 reduced motion에서 회전을 멈추고 glyph와 visible text를 유지합니다.
